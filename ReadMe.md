Superitems will always be completely free and open sourced. SuperItems was developed for paper servers, I do not recommend trying to run it on any other type of server. I ask that you do not reupload my work and monetize it (Do not sell this plugin). For those wanting to copy the plugin files to make your own version (fork), all I ask is that you add this github to your credits. Overall, have fun. Download the Jar for a usable version, download the zip for the full uncompiled plugin files.
